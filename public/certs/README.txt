Drop your certificate screenshots in this folder with these exact filenames
(PNG format). Each one will automatically appear on its certification card
on the website — no code change needed. Missing files are hidden automatically.

  aws-ccp.png                        -> AWS Certified Cloud Practitioner
  azure-ai-900.png                   -> Microsoft Azure AI Fundamentals (AI-900)
  belkasoft-windows-forensics.png    -> Belkasoft Windows Forensics
  soc-bootcamp.png                   -> SOC Operations Bootcamp (Splunk, ThinkCloudy)

CompTIA Security+ has no image slot because it is listed as "studying towards",
not yet held. Once you pass it, tell Claude and the card will be switched to
held with a "security-plus.png" slot added.

Tips:
- Landscape screenshots look best (the thumbnail is cropped from the top).
- If your file is .jpg instead of .png, either rename it or update the
  matching "image" path in src/data/index.ts.
